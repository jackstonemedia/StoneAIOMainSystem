## Deviations

1. Blueprint said `sendDefaultPii: false` in both `Sentry.init` calls. The installed
   `@sentry/*` v11 has NO `sendDefaultPii` option (tsc TS2353) — dropped from both
   init calls; the SDK does not attach user PII by default, and our code passes only
   error + method/path / component-stack context. Blueprint updated to match.
2. Blueprint placed the test route before `errorHandler` (after all routers). It must
   sit BEFORE global `resolveWorkspace` or it 401s — moved to the health/webhook
   section with the same pattern as the webhooks. Blueprint's route behavior is unchanged.
3. Server `beforeSend` in `@sentry/node` v11 runs asynchronously — the server test
   polls briefly for the event instead of asserting synchronously.
