## Known limitations (stated explicitly)

1. **Live Gemini style-summary generation is UNVERIFIED in this environment.**
   The dev `.env` has `GOOGLE_AI_API_KEY` as an empty placeholder (2 chars),
   so the endpoint correctly returns 503 ("AI is not configured…") and the
   sample stays saved. The code path is verified; the live AI call is not.
   A real key (via the secure flow, never chat) is needed before live AI
   features — interview turns (M2) and drafting (M3) included — can be verified
   end to end. This is dependency D6 from the M0 audit, not a code blocker:
   the endpoint degrades gracefully and the manual summary + approve path is
   verified live.
2. **RESEND_API_KEY is likewise an empty placeholder in dev `.env`.**
   No real sends were attempted or verified in M1 (out of scope here); M3's
   test-send verification will need a real key or will verify the send path
   without actual delivery. Flagged for the same secure-flow decision.
3. 90-day nudge line: logic verified in code (`updatedAt` > 90 days → line);
   not captured in a screenshot because the dev profile is fresh. No data was
   faked to force it.
4. Screenshots show DEV seed data (Sparkling Homes), not real business data.

## Test script for Jack (M1)

1. Open Email Marketing → click "Create with AI" (top right, next to the
   untouched AI Copilot button).
2. If no profile exists: fill the 3 screens (basics → sending details →
   optional extras; screen 3 offers "Skip for now"). Required fields block
   Continue until filled; optionals never block.
3. On screen 1, try "Have a website? Paste it and we will fill this in":
   paste a website link, click "Fill from website" — suggestions appear labeled
   "From your website" with "nothing is saved until you confirm". Click
   "Apply suggestions" to fill the form, then save.
4. After saving, the confirm card shows your profile with "Looks right,
   continue" and "Edit". Click Edit — a side panel opens; change something,
   save, and you return to the same place.
5. Click "Add examples of your writing" (or open Email Marketing → Profile):
   paste text or upload a .txt/.docx/.pdf (max 10 samples). Click "Generate
   style summary" — with no AI key configured you get an honest error and the
   sample stays saved; you can also write/edit a summary yourself and approve it.
6. Leave all optional fields empty and confirm — the flow still proceeds and
   invents no claims (drafting itself lands in M3).
